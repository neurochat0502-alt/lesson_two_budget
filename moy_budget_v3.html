Отчёт за произвольный период

Валюта учёта

Переключение валюты не является конвертацией: числовые суммы остаются прежними. Для учёта используйте только одну валюту.

Место хранения данных

При смене места хранения данные копируются в выбранное хранилище, старый источник не удаляется. Переход в режим сеанса или памяти повышает риск потери данных. Файл JSON — независимая резервная копия, а не автоматическая синхронизация.

Уведомления

Уведомления выводятся внутри приложения. Это не системные push-уведомления и не отправка сообщений.

Резервное копирование

JSON позволяет перенести данные с другого устройства. Восстановление заменяет активную базу; синхронизация с облаком и банком в этой автономной версии отсутствует.
