# Мой бюджет

Автономный сайт для учёта личных финансов: приветственная страница и рабочее приложение. Сервер, регистрация и облако не нужны — данные остаются в браузере.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Лендинг: возможности, как начать, приватность |
| `moy_budget_v3.html` | Приложение: операции, бюджеты, цели, отчёты, настройки |
| `LICENSE` | Лицензия MIT |
| `черн/` | Черновики, в репозиторий не входят |

## Возможности приложения

- Доходы и расходы с категориями, поиском и точными суммами до копеек
- Лимиты на месяц и финансовые цели
- Диаграммы, отчёт за период, CSV и печать
- Светлая и тёмная тема (кнопка в правом нижнем углу)
- Хранение в браузере, сеансе или только в памяти страницы
- Резервная копия JSON

## Как открыть

1. Скачайте или клонируйте этот каталог.
2. Откройте `index.html` в браузере.
3. Нажмите **Начать учёт** — откроется `moy_budget_v3.html`.

Можно открыть файл напрямую или поднять любой статический сервер в папке проекта.

## Данные и безопасность

- Финансовые записи не уходят на сервер.
- Очистка данных сайта, другой браузер или другое устройство — это другая база.
- Перед сменой компьютера скачайте JSON в разделе «Настройки».
- Переключение валюты меняет только обозначение, суммы не конвертируются.

## Разработка

Проект учебный, без сборщика и зависимостей. Правки вносятся в HTML-файлы. Черновики лежат в `черн/` и игнорируются Git.

Если Git ещё не инициализирован:

```bash
git init -b main
git add index.html moy_budget_v3.html README.md LICENSE .gitignore
git commit -m "Initial commit: landing and budget app"
```
